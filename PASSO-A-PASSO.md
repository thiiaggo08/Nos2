# Passo a passo: do repositório ao app "Nós 2" no iPhone

## O que tem neste repositório

| Arquivo | O que é |
|---|---|
| `PROJETO.md` | O plano completo do app: estrutura, regras e decisões |
| `CONTEUDO-FASE2.md` | Todo o texto novo, marcado como APROVADO ou PENDENTE |
| `espero-voce.html` | Protótipo do jogo Espero Você |
| `nos-dois.html` | Protótipo do Nós Dois |
| `PASSO-A-PASSO.md` | Este guia |

## Passo 1: abrir o Claude Code

1. No app do Claude, abra o **Claude Code**, ou acesse claude.ai/code no Safari.
2. Se ele pedir, conecte sua conta do GitHub.
3. Escolha o repositório **thiiaggo08/Nos2**.

## Passo 2: colar a mensagem inicial

Copie e cole no Claude Code:

> Leia o PROJETO.md, o CONTEUDO-FASE2.md e os dois protótipos HTML. Monte o app "Nós 2" como PWA offline, seguindo o plano.
> Fase 1: entrada com PIN, página principal, configurações, migração do Espero Você e do Nós Dois sem mudar o texto, correção de privacidade dos códigos e publicação no GitHub Pages.
> Depois implemente só o que estiver marcado como APROVADO no CONTEUDO-FASE2.md. Não invente conteúdo novo: o que estiver PENDENTE fica para depois.
> No fim, me passe o link para instalar no iPhone.

## Passo 3: acompanhar e aprovar

- O Claude Code vai mostrar o que está fazendo e pode fazer perguntas. Responda como faria comigo.
- Se ele pedir para ativar o **GitHub Pages**, siga as instruções dele. Normalmente fica em Settings → Pages → Branch: main.
- Antes de qualquer texto novo entrar no app, ele deve pedir sua aprovação.

## Passo 4: instalar nos dois celulares

1. Abra no **Safari** o link que o Claude Code passar. Tem que ser o Safari, não o Chrome.
2. Toque em **Compartilhar** (o quadrado com a seta para cima).
3. Toque em **Adicionar à Tela de Início** e confirme o nome **Nós 2**.
4. Abra pelo ícone novo, crie seu PIN e faça a configuração.
5. Repita no celular do seu par: um escolhe Jogador A, o outro Jogador B, e os dois usam a mesma senha do casal.

Depois da primeira abertura, o app funciona sem internet.

## Passo 5: testar juntos

- Façam uma Partida rápida com o mesmo código e confiram se cada um recebeu cartas diferentes.
- Gerem o código do placar num celular e colem no outro.
- Ponham o celular em modo avião e confiram se tudo continua abrindo.

## Passo 6: próximas fases

O conteúdo PENDENTE do CONTEUDO-FASE2.md (Rituais, prêmios e itens novos do Nós Dois) está sendo escrito no Claude. A cada parte aprovada:
1. O CONTEUDO-FASE2.md é atualizado aqui no repositório.
2. No Claude Code, peça: "Implemente as seções novas marcadas como APROVADO no CONTEUDO-FASE2.md."

## Se algo der errado

- **O app não atualizou:** feche o app (arraste para cima) e abra de novo, com internet.
- **Esqueceu o PIN:** use "Apagar tudo e recomeçar". Antes disso, se puder, exporte o backup em Configurações.
- **Os códigos não batem entre os celulares:** confiram se a senha do casal é exatamente igual nos dois.
